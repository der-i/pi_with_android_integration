# Система мониторинга теплицы

## Описание
Система мониторинга микроклимата для теплицы с датчиком DHT22 на Raspberry Pi и Android приложением для контроля параметров в реальном времени.

## Архитектура
```
DHT22 → Raspberry Pi → Flask API → Android App
```

## Стек технологий
- **Backend**: Python 3, Flask, SQLite
- **Hardware**: Raspberry Pi, DHT22 (AM2302)
- **Mobile**: Android (Java), Material Design, MPAndroidChart

## Функциональность

### Мониторинг
- Отображение температуры и влажности в реальном времени
- Графики изменения показаний (MPAndroidChart)
- История данных с фильтрацией по периодам
- Автообновление с настраиваемым интервалом (2с-1мин)

### Уведомления
- Push-уведомления при выходе за пороговые значения
- Настройка min/max для температуры и влажности
- Защита от спама (cooldown 60 сек)
- Тестирование уведомлений

### Интерфейс
- Material Design 3
- Навигационное меню (drawer)
- SwipeRefreshLayout для ручного обновления
- Адаптивные карточки для отображения данных
